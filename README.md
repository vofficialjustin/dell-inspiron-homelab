# Dell Inspiron 531 Home Lab

## Overview

This project focuses on repurposing an older Dell Inspiron 531 desktop computer into a personal home lab for learning Linux system administration, networking, virtualization, containerization, cybersecurity, and self-hosting.

The goal is to transform existing hardware into a functional server environment while gaining hands-on experience with technologies and concepts used in IT infrastructure.

Throughout this project, I will document hardware specifications, system installations, network configurations, troubleshooting procedures, and lessons learned.

## Project Objectives

- Learn Linux server administration and command-line operations.
- Understand networking concepts such as IP addressing, DNS, DHCP, and SSH.
- Practice securing and managing a Linux server.
- Explore virtualization and virtual machines.
- Learn Docker and container management.
- Host applications and databases locally.
- Build practical troubleshooting and system administration skills.
